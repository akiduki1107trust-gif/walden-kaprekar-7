Research Overview

A computer-assisted proof candidate for Walden’s Seven-Digit Kaprekar Conjecture (2005), for all integer bases b ≥ 22.

The seven-digit case of Thakur’s 2019 base-periodicity prediction follows as a corollary, conditional on the main proof.
